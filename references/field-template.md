# 书籍表字段模板（给还没有表的人参考）

> 这是建议结构，不是强制要求。字段名你可以自己起——agent 会在初始化时自动读取你的字段名并建立映射。
> 如果你已经有表了，直接跳到 init-guide 第1步发链接就行，不用看这个文件。

## 建议建这些字段

| 语义角色 | 建议字段名 | 类型 | 说明 |
|---|---|---|---|
| 书名（主字段） | 书名 | 文本 | 放书名，建议用《》包裹 |
| 作者 | 作者 | 文本 | |
| 分类/标签 | 标签 | 多选 | 自己加选项，比如心理学、AI、文学 |
| 出版日期 | 出版日期 | 日期 | 可选 |
| 简介 | 简介 | 多行文本 | 可选 |
| 阅读日期 | 读完日期 | 日期 | 待读=加入日；已读=读完日；在读=开始读日 |
| 阅读状态 | 状态 | 单选 | 选项自己定，比如：待读 / 在读 / 已读 |
| 读书笔记 | 笔记 | 多行文本 | 可选 |

## 关于日期格式

- **飞书表内显示格式**：你在表里建日期字段时可以设成 `yyyy/MM/dd` 或其他格式，这只是给人看的
- **API 写入格式**：agent 写入时统一用 `YYYY-MM-DD HH:mm`（比如 `2026-09-24 00:00`），这是 lark-cli 要求的格式，和你表里的显示格式无关

## 关于分类选项

- 你想加什么选项就加什么，agent 不会自创选项，只会从你已有的选项里选
- 如果某本书的分类不在你现有选项里，agent 会问你要不要加新选项

## 视图设置

建完表后，把主视图设置为按"阅读日期"字段倒序排列。这样新书自动排在最上面。
